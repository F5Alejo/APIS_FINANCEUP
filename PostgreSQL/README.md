# Scripts de Base de Datos (PostgreSQL)

Esta carpeta contiene los scripts SQL necesarios para estructurar e inicializar la base de datos `FinanceUp`.

## Contenido

- **`crear sql (1).txt`**: Script para la creación inicial de las tablas, esquemas, tipos enumerados y relaciones en la base de datos.
- **`insertar sql (1).txt`**: Script para poblar la base de datos con datos semilla o iniciales (inserts).
- **`actualizar sql (1).txt`**: Script de alteraciones, actualizaciones o parches aplicados a la estructura original.

## Uso
Para levantar la base de datos desde cero, asegúrese de ejecutar los scripts en el orden lógico (primero la creación de la estructura y luego las inserciones de datos).
